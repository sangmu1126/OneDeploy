# 후속 실환경 검증 계획

기준: 2026-10-06. 이 문서는 **아직 통과하지 않은 실환경 검증**의 실행 조건과
합격 기준을 기록한다. 기존에 통과한 드릴과 자원 상태는 [현재 상태](status.md)와
[AWS 실계정 기록](aws-postgres-live-runbook.md)을 따른다. 구현·모의 테스트·로컬
HTTP 검증은 계속 수행하며, 실제 호출이나 클라우드 확인을 하지 않은 결과를
"검증 완료"로 표시하지 않는다.

## 지금 계속할 검증

- 변경된 코드의 단위·통합 테스트와 정적 검사, 로컬 Docker 빌드·HTTP·정리를 실행한다.
- 고정 AI 응답은 요청 형식, 코드 변경 전달, 정책 경계와 실패 처리를 확인하는 데 쓴다.
  모델의 실제 판단 품질이나 API 가용성을 증명한 것으로 기록하지 않는다.
- 배포 증명서에는 테스트 종류와 확인한 범위, 생략한 실환경 검증을 별도 항목으로 남긴다.
  기능이 아직 구현되지 않았다면 문서에서도 완료로 표시하지 않는다.

## 나중에 실행할 실환경 검증

| 항목 | 실행 조건 | 합격 기준 | 현재 상태 |
| --- | --- | --- | --- |
| 실제 OpenAI 모델을 거친 전체 배포 | API 키 준비, 모델 호출 비용 허용, 임시 앱·종료 경로 준비 | 실제 응답으로 소스 변경·대상 선택을 수행하고 원본 보존, 클라우드 HTTP 응답, 자원 정리까지 확인 | 키가 없어 미실행. 고정 응답과 전송 형식 테스트만 통과 |
| 단일 이미지 로컬 리허설과 AWS 승격 | 단일 빌드·승격 구현, AWS 임시 자원 및 비용 확인 | 로컬 리허설에 사용한 산출물과 ECR·실행 중 ECS 이미지의 동일성을 이미지 구성·매니페스트 다이제스트로 확인하고 HTTPS 응답 및 정리를 기록 | 설계 단계. 현재 Local·AWS는 별도 빌드 |
| Cloud Run 실계정 배포·승격 | GCP 프로젝트·권한·과금 설정과 임시 리소스 정리 경로 준비 | 배포 URL의 HTTP, 접근 정책, 이미지 다이제스트, 종료 및 남은 자원을 확인 | 어댑터 테스트만 통과; 실계정 미실행 |
| AWS의 아직 미실행인 제품 경로 | 해당 코드 변경 완료, 읽기 전용 소유권·비용 사전 점검, 임시 자원 준비 | ASGI·직접 실행 Python HTTP, 변경된 SQL 마이그레이션 정리 API 등 해당 경로의 성공·실패·정리를 각각 확인 | [현재 상태](status.md)의 경로별 기록 참조 |
| 환경 간 영속 데이터 이동 | 공통 데이터 계약·이전 절차 구현, 시험 데이터와 복구 지점 준비 | 원본·대상 스키마와 데이터 표식, 앱 읽기/쓰기, 전환 실패 시 원본 유지·복구 확인 | 기능과 실환경 드릴 모두 미완료. 기존 AWS RDS 스키마 마이그레이션과 별개 |
| 운영 범위 확장 | 다중 사용자 격리·취소·비용 통제·CI/CD·비 AWS 복구 기능별 구현 | 기능별 권한, 실패·재시작, 비용·자원 정리 및 회귀 테스트를 확인 | 기능별 미완료 범위는 [현재 상태](status.md) 참조 |

실환경 실행 시에는 날짜, 앱/작업 식별자, 사용한 이미지 다이제스트, 실제 HTTP·
데이터 결과, 실패 여부, 발생 비용의 조회 시점, 정리 후 남은 자원을 기록한다.
AWS의 보존된 `demo-app` DB는 시험 데이터로 재사용하더라도 종료 후 `stopped`
상태와 스냅샷 보존을 다시 확인한다. 구현이 바뀌면 해당 항목의 합격 기준을 먼저
갱신하고, 검증을 통과한 뒤에만 [현재 상태](status.md)의 완료 범위에 반영한다.
