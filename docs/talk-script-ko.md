# 한국어 발표 초안

OneDeploy는 앱을 올리고 배포를 요청하면 AI가 실제 배포 작업을 수행하는 도구입니다.
개발자가 실행 명령, Dockerfile과 환경별 설정을 직접 준비해야 하는 수고를 줄이고자 했습니다.

AI는 앱 소스를 읽고 작업용 복사본을 수정하며, 실제 빌드와 실행 도구를 사용합니다.
실패하면 도구가 반환한 로그를 보고 수정한 뒤 다시 시도합니다.
완료 여부는 AI의 설명이 아니라 실제 HTTP 응답으로 판정합니다.

현재 구현한 대상은 Node.js 앱의 Local Docker, AWS ECS Express 및 Cloud Run 배포 어댑터입니다.
개발 테스트에서는 AI의 도구 선택만 고정 응답으로 대체하고 파일 수정·Docker 배포·실패 복구를 실제 검증했습니다.
AWS ECS Express는 실제 계정에서 공개 HTTPS 응답과 동일 앱 ID의 v1→v2 재배포 시 URL 유지를 검증했습니다. 실제 AI 판단과 Cloud Run 실배포는 별도로 검증해야 합니다.

이 문서는 현재 구현 기준의 초안이며 실제 AI 검증 및 클라우드 확장 결과에 맞춰 최종 발표 전에 갱신합니다.
